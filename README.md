# VertexAi Demo(LMOps)


# How to run?
### STEPS:

Clone the repository

```bash
Project repo: https://github.com/
```
### STEP 01- Create a conda environment after opening the repository

```bash
conda create -n vertexaidemo python=3.8 -y
```

```bash
conda activate vertexaidemo
```

### STEP 02- install the requirements

```bash
pip install -r requirements.txt
```

### STEP 03- Create a .env file in the root directory and add your project id and region

```bash
project_id  = "xxxxxxxxxxxxxxxxxx"
region      = "xxxxxxxxxxxxxxxxxx"
```

### STEP 04 - Finally run the following command

```bash
python app.py
```
